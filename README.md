# 빌띵 (Billding)

띵타이쿤(ddingtycoon.kr) 서버용 **골드 수입/지출 자동 집계** 클라이언트 전용 QoL 모드.

화면에 이미 보이는 정보(골드 잔고 표시 · 채팅 로그 · 열어 본 창의 설명문)만 재구성·집계합니다.
자동화·정보우위 기능은 없습니다.

- MC **1.21.4** / Java **21** / **Fabric · NeoForge** 양쪽 지원 / 클라이언트 전용
- 판매(수입) · 구매(지출) · 은행/플리마켓 금고 이체 · 수수료를 자동 분류·집계
- `/빌띵` 명령어 + HUD 오버레이로 오늘/주간 정산 표시
- 엑셀(.xlsx) 내보내기 — 거래내역 · 일별 · 주별 · 카테고리 4시트

## 명령어

한글이 기본이고 영문은 별칭입니다. 마인크래프트 채팅창에서 한글 IME가 안 먹는 환경이 있어
영문(`/dtstat …`)도 그대로 살려 둡니다.

| 명령어 | 하는 일 |
|---|---|
| `/빌띵` | 정산 창 (오늘 · 주간 · 내역 · 금고 · 관리 · 설정) |
| `/빌띵 오늘` | 오늘 정산을 채팅으로 |
| `/빌띵 주간` | 최근 7일 |
| `/빌띵 날짜 2026-08-16` | 특정 날짜 |
| `/빌띵 미분류` | 분류되지 않은 내역 |
| `/빌띵 금고 [금액]` | 플리마켓 금고 잔액 확인·설정 (최초 1회 입력 후 자동 갱신) |
| `/빌띵 내보내기 [범위]` | 엑셀·CSV 내보내기 (`week`, `2026-06` 등) |
| `/빌띵 추가 지출 5000 강화` | 수동 기록 추가 |
| `/빌띵 설정` · `/빌띵 표시` · `/빌띵 위치` | 설정 화면 · HUD 켜고 끄기 · HUD 위치 조정 |
| `/빌띵 초기화` | 오늘 데이터 초기화 |
| `/빌띵 진단` | 지금 무엇을 읽고 있는지 출력 (버그 제보용) |

## 어떻게 집계하나

돈이 움직였다는 사실은 두 갈래로 들어옵니다.

1. **채팅** — "…을 판매하여 12,000골드를 획득했습니다" 처럼 메시지에 금액이 있는 경우
2. **잔고 변동(ΔG)** — 화면의 골드 숫자가 바뀐 것

둘을 시간창 안에서 짝지어 한 건의 기록을 만듭니다. 채팅에 금액이 있으면 그 금액을 쓰고 ΔG로 교차검증하며,
강화·수리·전문가 스킬처럼 금액이 채팅에 없는 거래는 **열어 본 창에 적힌 비용**을 우선 근거로 씁니다.

어느 쪽으로도 금액을 확정하지 못하면 **조용히 버리지 않고** 금액 0 · "미확인"으로 남깁니다.
빠진 걸 사용자가 알아챌 수 있어야 하기 때문입니다.

## 빌드

Gradle Wrapper가 포함돼 있어 별도 설치 없이 실행됩니다.

```bash
./gradlew build        # 배포 jar 생성 (fabric/build/libs, neoforge/build/libs)
./gradlew :fabric:test # 파서·정산 오프라인 검증 (JUnit)
```

> ⚠️ **경로 주의**: OneDrive 동기화 폴더나 한글 경로에서 빌드하면 Loom 파일락·디컴파일 문제가 납니다.
> `C:\dev\billding` 같은 ASCII 경로로 복사해서 빌드하세요.

## 구성

| 모듈 | 내용 |
|---|---|
| `common` | 파싱 · 정산 · 집계 · 저장 · 엑셀 내보내기. 마인크래프트에 의존하지 않아 그대로 테스트 가능 |
| `fabric` | Fabric 로더 구현 (Loom / yarn) + 테스트 |
| `neoforge` | NeoForge 로더 구현 (moddev / mojmap) |

## 컴플라이언스

> **"거울이지 망원경이 아니다."**

이미 화면에 보이는 정보의 재구성·집계만 수행합니다.

- 서버로 **아무것도 전송하지 않습니다**
- 자동화·치트 기능 없음. 모든 감시기는 읽기 전용
- 표시되지 않는 정보를 캐거나 시세를 탐색하지 않습니다

저장소에는 서버 리소스팩에서 추출한 이미지가 포함돼 있지 않습니다. 우리 저작물이 아니기 때문입니다.

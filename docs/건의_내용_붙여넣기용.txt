안녕하세요, 편의성 모드로 골드 가계부 모드 "빌띵"을 제작해서 서버에서 사용해도 되는지 검사 부탁드립니다.

■ 모드가 하는 일
화면에 이미 표시되는 정보(좌상단 골드 잔고, 채팅 로그)만 읽어서 오늘 하루 수입/지출을 자동으로 더하고 분류해 보여주는 클라이언트 전용 가계부 모드입니다.
- HUD로 오늘 순익/수입/지출을 화면 한켠에 표시
- 정산 창(오늘/주간/내역/직업별 통계)을 명령어로 열람
- 플리마켓 금고 잔액은 유저가 처음 1회 직접 입력하면 이후 채팅을 보고 자동 갱신
- 채팅으로 안 잡히는 항목은 유저가 직접 수동으로 입력 가능
딱 여기까지이며, 시세 조회, 최저가 탐색, 자동 거래, 자동 채집, 매크로, 서버 데이터 조회 같은 기능은 전혀 없습니다.

■ 왜 문제가 없다고 생각하는지
허용 모드 안내에 나온 "서버에서 직접적인 이득(자동화, 치트성, 정보 우위)을 주는 기능은 금지"라는 기준에 하나씩 대조해봤습니다.
- 자동화 아님: 모드는 읽기만 합니다. 마우스나 키보드 입력을 대신 하지 않고, 어떤 행동도 자동으로 실행하지 않습니다.
- 치트성 아님: 게임 판정이나 서버 데이터를 조작하지 않습니다. 화면에 이미 뜬 숫자를 더하고 빼는 계산만 합니다.
- 정보 우위 아님: 시세, 재고, 타 유저 정보 등 화면에 안 보이는 정보는 전혀 조회하지 않습니다. 본인이 이미 볼 수 있는 잔고와 채팅을 재구성해서 보여줄 뿐입니다.

자체적으로 세운 기준은 이렇습니다. 지금 이 정보가 화면에 이미 떠 있는가, 저장하고 더하기만 하는가, 유저가 손으로 직접 세거나 메모장에 적어도 똑같은 결과를 얻을 수 있는가. 세 가지 다 통과하는 기능만 만들었습니다.

■ 이미 승인된 모드와의 비교
허용 모드 목록의 유저 자체 제작 섹션에 등재된 Count Easy(상자를 열면 내부 아이템 개수를 자동 집계해 메모장처럼 보여주는 모드)와 컨셉이 사실상 같다고 생각합니다. 둘 다 이미 화면에 보이는 정보(상자 안 아이템 / 채팅과 잔고)를 자동으로 집계해서 보여줄 뿐, 서버와 상호작용하지 않고 유저가 손으로도 할 수 있는 일을 대신 계산해주는 것뿐입니다.

■ 기술적으로 투명하게 만들었습니다
- environment: client로 설정되어 서버 측 개입이 전혀 없는 순수 클라이언트 전용 모드입니다.
- 네트워크 통신 코드가 없습니다. 자체 서버로도 외부로도 아무 데이터를 전송하지 않고, 모든 데이터는 제 컴퓨터 로컬 폴더에만 저장됩니다.
- 오픈소스(MIT 라이선스)로 만들어서 필요하시면 전체 소스코드를 보여드릴 수 있습니다.
- 필수 의존성은 Fabric API, 선택 의존성은 YACL(YetAnotherConfigLib)인데 둘 다 이미 허용 모드 의존성 목록에 등재되어 있는 항목입니다.
- Fabric과 NeoForge 양쪽 로더 버전을 만들었고, 마인크래프트 1.21.4 기준입니다.

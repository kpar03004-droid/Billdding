## 1. 한 줄 요약

**빌띵**은 게임 화면에 이미 표시되는 정보(좌상단 골드 잔고, 채팅 로그)만 읽어서 오늘의 수입·지출을 자동으로 더하고 분류해 보여주는 **클라이언트 전용 가계부 모드**입니다. 서버에 아무것도 보내지 않고, 화면에 없는 정보는 절대 수집하지 않으며, 자동으로 아무 행동도 하지 않습니다.

---

## 2. 모드가 실제로 하는 일

| 기능 | 데이터 출처 | 설명 |
|---|---|---|
| 오늘 수입/지출 HUD | 좌상단 골드 잔고 + 채팅 | 판매·구매·이체 시 화면에 뜨는 채팅 문구를 읽어 오늘 누계를 화면 한켠에 표시 |
| `/dtstat` 정산 창 | 위와 동일 | 오늘/주간/내역/직업별(광물·사냥꾼·요리 등) 통계를 GUI로 표시 |
| 플리마켓 금고 잔액 추적 | 유저가 직접 1회 입력 + 이후 채팅 | 유저가 처음 한 번 실제 잔액을 입력하면, 이후 판매·구매·입출금 채팅을 보고 자동으로 갱신 |
| 수동 기록 추가/초기화 | 유저 입력 | 채팅으로 안 잡히는 항목을 유저가 직접 추가하거나 오늘 기록을 초기화 |

**딱 여기까지입니다.** 시세 조회, 최저가 탐색, 자동 거래, 자동 채집, 매크로, 서버 데이터 조회 등은 전혀 없습니다.

---

## 3. 왜 금지 행동에 해당하지 않는가

허용 모드 안내 문서의 판단 기준을 그대로 대조했습니다.

> **"서버에서 직접적인 이득(자동화, 치트성, 정보 우위)을 주는 기능은 명시 여부와 관계없이 금지"**

| 금지 유형 | 빌띵 해당 여부 | 근거 |
|---|---|---|
| 자동화 (입력 자동화·매크로) | ❌ 아님 | 모드는 **읽기만** 합니다. 마우스·키보드 입력을 대신 하지 않고, 어떤 행동도 자동 실행하지 않습니다. |
| 치트성 | ❌ 아님 | 게임 판정·서버 데이터를 조작하지 않습니다. 모든 계산은 클라이언트 화면에 이미 뜬 숫자의 덧셈/뺄셈뿐입니다. |
| 정보 우위 | ❌ 아님 | 시세·재고·타 유저 정보 등 화면에 없는 정보는 조회하지 않습니다. 본인이 이미 볼 수 있는 잔고·채팅을 다시 보여줄 뿐입니다. |

**자체 검증 3문항** (모든 기능이 통과해야만 구현):
1. 지금 이 정보가 화면에 이미 떠 있는가? — 예 (잔고 숫자, 채팅 문구)
2. 저장하고 더하기만 하는가? — 예. 판정·추측·예측 없음
3. 유저가 손으로 직접 세거나 메모장에 적어도 똑같은 결과를 얻을 수 있는가? — 예. 빌띵은 이 수작업을 대신 계산해줄 뿐

---

## 4. 이미 승인된 선례와의 비교

허용 모드 목록의 **"유저 자체 제작"** 섹션에 이미 등재된 `Count Easy`와 컨셉이 사실상 동일합니다.

| | Count Easy (승인됨) | 빌띵 |
|---|---|---|
| 하는 일 | 상자를 열면 내부 아이템 총 개수·스택 수를 **자동 집계**해 메모장처럼 표시 | 채팅·잔고에 뜬 거래 내역을 **자동 집계**해 정산 창에 표시 |
| 데이터 출처 | 이미 열려 있는 상자(화면에 보임) | 이미 뜬 채팅·잔고(화면에 보임) |
| 서버 상호작용 | 없음 | 없음 |
| 유저가 수작업으로도 가능한가 | 예(손으로 세면 됨) | 예(메모장에 적으면 됨) |

또한 같은 방식으로 **공식 허가받은 "타이머 모드"**(제작 시간·쿨타임 표시, 위키 자료실 게시)도 클라이언트 전용·화면 정보 재구성 원칙으로 이미 승인된 선례입니다.

---

## 5. 기술적 투명성

- **`environment: client`** — 서버 측 개입 전혀 없음. 순수 클라이언트 전용 모드
- **네트워크 통신 코드 없음** — 자체 서버로도, 외부로도 아무 데이터를 전송하지 않음. 모든 데이터는 로컬 `config/billding/` 폴더에만 저장
- **오픈소스(MIT)** — 전체 소스코드 공개, 운영진이 원하시면 직접 코드 리뷰 가능
- **의존성이 이미 화이트리스트 등재됨** — 필수: **Fabric API**, 선택: **YACL(YetAnotherConfigLib)** — 둘 다 [허용 모드 §⚙️ 의존성](https://wiki.ddingtycoon.kr/ko/articles/%ED%97%88%EC%9A%A9-%EB%AA%A8%EB%93%9C-e8c56678)에 이미 등록된 항목
- Fabric / NeoForge 양쪽 로더 지원

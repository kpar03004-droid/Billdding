# 판매 물품 카탈로그 (띵타위키 기반, 2026-07-20)

세레니티 기준. 출처: `띵타이쿤/data/세레니티/**`. 파서 라벨 검증·카테고리 세분화용 참고 자료.

## 🔑 파싱 관점 핵심 (먼저 읽기)

- **판매 메시지 형식**: `[등급] 품목명 아이템 N개를 X골드에 판매하셨습니다.`
  - 확인된 실물: `[RARE] 평범한 표범 아이템 1개를 18,314골드에 판매하셨습니다.` / `[ROOKIE] 코룸 정동석 아이템 19개를 182,400골드에 판매하셨습니다.`
- **품목명이 매우 다양**(물고기 100+종, 귀중품, 광석, 동물…)하지만, `CurrencyParser`의 SALE 규칙이 품목명을 `(.+?)`로 통째로 캡처 → **품목 하드코딩 불필요. 모든 판매가 자동 처리됨.**
- ⚠️ **NPC별 판매 문구 차이 가능성**(보류 #2, 코딩계획서 §7):
  - 확인됨: 채광 정동석 = `판매하셨습니다` (사냥 육식동물과 동일 형식).
  - 미확인(내일): 물고기→**샤키**, 공룡 원혼→**픽스**, 육식동물→**수렵꾼** 판매 문구. 형식이 다르면 규칙 행 추가.
- **직업 분류 구현됨**(`SaleCategory`): 광물 · 사냥꾼 · 배 낚시 · 해양(수중어획) · 요리 · 재배 · 무역 · 판매(미분류). 물고기="배 낚시", 수중어획(굴·소라·★)="해양"으로 분리. 키워드 배열에 품목 추가로 확장.

## ⛏️ 채광 (판매: 상점/유저거래 · 정동석→세공→귀중품)

- **광석**: 코룸 · 리프톤 · 세렌트
- **정동석**: 코룸 정동석 · 리프톤 정동석 · 세렌트 정동석 (NPC 로니 감정 → 보석)
- **보석**(감정 결과): 키론·테라온·실바니움(코룸계) / 라온·제피르·아스트랄(리프톤계) / 넬트·세피아·피로시아(세렌트계)
- **귀중품**(고가 판매, 세공 시설 제작): 키론 오르골 · 테라온 축음기 · 실바니움 만년필 · 라온 만화경 · 제피르 라이터 · 아스트랄 이어커프 · 넬트 천체관측기 · 세피아 회중시계 · 피로시아 단안경 (+ `탁월한 ~` Mythic, 기본가 최대 236,340G)
- **주괴/가공**: 코룸/리프톤/세렌트 주괴 · 강화 횃불 · 조약돌 뭉치 · 심층암 조약돌 뭉치 · 기름통 · 미감정 토파즈 보석함/사파이어 조각상/플래티넘 왕관
- **유물(항해)**: 탈리세르의 나뭇잎 · 데르무스의 가죽 · 카이로스카의 조각 · 실파드라의 술병 · 아스트라곤의 뼈

## 🏹 사냥 (판매: 수렵꾼=육식동물 · 픽스=공룡 원혼)

- **육식동물**(포획 → 수렵꾼 판매): 사자 · 표범 · 악어 · 늑대 · 호랑이 — 등급 `쇠약한`/`평범한`/`건강한`
- **공룡 원혼**(소환·처치 → 픽스 판매): 우티 · 라프 · 크록 · 헤탄 · 듀크
- **초식동물 전리품**(주로 각인용, 판매 여부 확인 필요): 사슴 뿔 · 미어캣 꼬리 · 기린 가죽 · 코끼리 상아 · 하마 송곳니 · 플라밍고 부리 · 칠면조 깃털 · 곰 발바닥

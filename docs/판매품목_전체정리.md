# 띵타이쿤 판매 품목 전체 정리 (카테고리 재정리용)

> 출처: `all_wiki_data.md` · 위키 각 전문가/콘텐츠 문서
> 목적: 카테고리 재분류 검토용. 판매처(NPC)와 등급 체계 병기.
> 표기: ⭐=NPC에게 골드로 판매되는 것이 확인/추정, ↔=유저거래 위주(NPC판매 제한 가능)

---

## 1. 채광 (Mining)

**광석** — 코룸 / 리프톤 / 세렌트
**주괴** — 코룸 주괴 / 리프톤 주괴 / 세렌트 주괴
**정동석** — 코룸 정동석 / 리프톤 정동석 / 세렌트 정동석 (→ 로니 감정 → 보석)
**보석**(감정 결과) — 키론·테라온·실바니움(코룸) / 라온·제피르·아스트랄(리프톤) / 넬트·세피아·피로시아(세렌트)
**귀중품** ⭐(로니 판매) — 등급: Common/Normal/Rare/Epic/Legendary/Mythic(탁월한)
- 키론 오르골 / 테라온 축음기 / 실바니움 만년필 / 라온 만화경 / 제피르 라이터
- 아스트랄 이어커프 / 넬트 천체관측기 / 세피아 회중시계 / 피로시아 단안경
- (Mythic은 "탁월한 ○○" 형태)
**가공/강화석** — 강화 횃불 / 조약돌 뭉치 / 심층암 조약돌 뭉치 / 어빌리티 스톤 / 라이프스톤(하·중·상급)
**보석함류** — 미감정 토파즈 보석함 / 미감정 사파이어 조각상 / 미감정 플래티넘 왕관
**기타** — 기름통 / 석유 / 드릴 / 광채 원석(바이올렛·오팔·아다만티움)

## 2. 재배 (Farming)

**작물** — 토마토 / 양파 / 마늘
**과일** — 파인애플 / 코코넛
**베이스·묶음** — 토마토 베이스 / 양파 베이스 / 마늘 베이스 / 감자 묶음 / 호박 묶음 / 당근 묶음 / 비트 묶음 / 수박 묶음 / 달콤한 열매 묶음
※ 작물·베이스·요리는 유저상점/플리마켓 판매 제한(마을원 거래만) — 규정 표 참고

## 3. 요리 (Cooking, → 밀키 판매) ⭐

- (커먼) 토마토 스파게티 / 어니언 링 / 갈릭 케이크
- (노멀) 삼겹살 토마토 찌개 / 삼색 아이스크림 / 마늘 양갈비 핫도그 / 달콤 시리얼 / 로스트 치킨 파이
- (레어) 스윗 치킨 햄버거 / 토마토 파인애플 피자 / 양파 수프 / 허브 삼겹살 찜
- (에픽) 토마토 라자냐 / 딥 크림 빠네 / 트리플 소갈비 꼬치

## 4. 바리스타 (Coffee, → 손님 판매) ⭐

블랙 커피 / 카페 모카 / 화이트 모카 / 드립 커피 / 콜드 브루 / 아메리카노
플랫 마끼아또 / 머쉬룸 마끼아또 / 코코아 마끼아또
돌체 라떼 / 그린티 라떼 / 우드 라떼
플라워 카푸치노 / 썬더 카푸치노 / 가든 카푸치노
스톤 블렌디드 / 쿠키 블렌디드 / 다크 블렌디드
그린트리 프라페 / 체리 블로썸 프라페 / 프로즌 스노우 프라페
실버문 아인슈페너 / 오로라 아인슈페너
※ 커피는 "거래 불가" — NPC 판매만

## 5. 사냥 (Hunting)

**육식동물** ⭐(수렵꾼 판매) — 사자 / 표범 / 악어 / 늑대 / 호랑이
- 등급: 쇠약한 / 평범한 / 건강한
**공룡 원혼** ⭐(픽스 판매) — 우티 / 라프 / 크록 / 헤탄 / 듀크
- 등급: 일반종 / 희귀종 / 환상종 (예: "회귀종 라프의 원혼", "일반종 라프의 원혼")
**초식동물 전리품**(도구 각인용, 판매 제한) — 사슴 뿔 / 미어캣 꼬리 / 기린 가죽 / 코끼리 상아 / 하마 송곳니 / 플라밍고 부리 / 칠면조 깃털 / 곰 발바닥
**초식동물 영혼** — 사슴·미어캣·기린·코끼리·하마·플라밍고·칠면조·곰의 영혼 (계약서 재료)
**각인석** — 수상한 각인석 조각 / 수상한 각인석 / 각인석

## 6. 해양 — 수중 어획물 (다이빙) ⭐

굴 / 소라 / 문어 / 미역 / 성게 (성급: ★ / ★★ / ★★★)

## 7. 해양 — 배 낚시 물고기 (→ 샤키 판매) ⭐

등급: Normal(520G) / Rare(1,300) / Epic(2,600) / Legendary(13,000) / Mythic(50,000) — × 길이·해역·전문가 배율
※ 채팅은 "배 낚시 물고기를 판매하여 …" 형태(개별 이름 대신 뭉쳐 나옴)로 확인됨

**해역별 물고기 이름**(참고):
- 평원: 토크·라디엔·모스핀·펠트·바르도·셀리스·피핀·젤루 / 튜튜·아샤·포포·킥·리자드론·티니 / 에스카·미라엘·자르간 / 가르가돈·시엘라 / 일루시아
- 산호초: 도르프·벨리스·미카·글릭·셀루엔·리포·카스피·플루아·아네모·코리 / 네크리스·피오레·크릴리·샤샤·에일론 / 벨
- 쓰레기: 글록·머크·레스틴·블롭스·벨치·드로크·슬러그·락·베르닉 / 바르가스토
- 심해: 크렉·블로키·스피니온·조드·드락스·옥토브·셀리온·그리브 / 파이린·아졸·볼루스·스톰리 / 오스카·모그리스·바르켄 / 스트라이·온 / 아크라센
- 크림슨: 라스트·크롭·벨릭스·플리프·그리드·모바·셀리·아스타 / 피올·제파·도르막·브루크·블라스토·크락스 / 루미아·스피카·네크론 / 볼그라드·조르탄 / 자르메돈
- 빙하: 플리스·크로겔·글립·스피크·셀리안·크리오·자벨·바모 / 블리자·베르티스·리포겔·제드라·시클론 / 아르크스·크라스토·볼그림 / 벨스카디
- 오염: 벡시스·그룸·플럭스·벨룩·더크·모그·토포·브라크·넥·슬리드 / 자르가디스

## 8. 낚시대회 / 파라다이스 어획물 합성 ⭐

"물고기를/생물을 합성했습니다. {획득품} N개, {금액}G (포인트 …)" 형태로 골드 지급
- 획득품 예: 하급 파도 결정석 (등급: 하급/중급/상급? 속성: 파도/불꽃/… 결정석)

## 9. 연금 (Alchemy)

**어패류 성급** — 굴/소라/문어/미역/성게 ★~★★★
**회**(생선 가공) — 도미 회 / 청어 회 / 금붕어 회 / 농어 회
**T1~T3 연금품**(T3 판매 가능) — 속성: 수호/파동/혼란/생명/부식
- 정수(★) / 핵(★) / 에센스(★★) / 결정(★★) / 엘릭서(★★★) / 영약(★★★)
- 예: 수호의 엘릭서 / 불멸 재생의 영약 / 파동 에센스

## 10. 항해 유물·보물 (→ 항해 수하물, NPC판매 여부 미확인)

**유물**(채광 드롭) — 탈리세르의 나뭇잎 / 데르무스의 가죽 / 카이로스카의 조각 / 실파드라의 술병 / 아스트라곤의 뼈
**보물**(보물상자) — 에르칼의 장갑 / 이그논의 탈리즈만 / 카르세나의 룬 / 실바르의 보석함 / 아르데온의 반지

## 11. 무역 ⭐

"무역 아이템을 N골드에 판매하였습니다." — 무역 콘텐츠 판매

## 참고: 판매 메시지 형식별 분류 (모드 파싱 관점)

| 메시지 형식 | 대상 |
|---|---|
| `[등급] 품목 아이템 N개를 X골드에 판매하셨습니다` | 사냥(육식·원혼)·채광(정동석/주괴)·요리·해양 등 대부분 |
| `품목 아이템을 X골드에 판매하였습니다` | 무역·유저상점 판매 |
| `품목을 판매하여 X골드를 획득했습니다` | 귀중품(로니)·물고기(샤키)·원혼(픽스) 등 NPC 위탁 |
| `물고기를/생물을 합성했습니다. … XG (포인트 …)` | 낚시대회/파라다이스 |

**미확인/추가 확인 필요**: 바리스타 커피·연금품·수중어획물의 실제 판매 채팅 문구 형식(어느 형식으로 뜨는지). 실제로 팔아서 채팅 문구를 확보하면 정확한 분류 가능.
